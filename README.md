Headspace Systems Studios built Headspace as a local-first application designed to give users full control over their data.
Data Collection:
Headspace does not collect, store, or transmit personal data to external servers. All data entered into the app remains on the user’s device unless explicitly exported by the user.
Data Storage:
All information, including names, tracking data, and logs, is stored locally on the user’s device. Users may export and import their data manually using provided features.
Data Sharing:
Headspace does not share user data with any third parties.
Permissions:
The app may request access to local storage for importing and exporting data files. This access is only used for these features and is not used for data collection.
Security:
Because data is stored locally, users are responsible for managing and securing their own data backups.
Children’s Privacy:
Headspace does not knowingly collect any personal information from children.
Changes to This Policy:
This privacy policy may be updated in the future. Any changes will be reflected within the app or associated distribution platforms.
